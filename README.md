# 寧靜居 Wiki

[![Deploy to GitHub Pages](https://github.com/cj0673/twcraft-wiki/actions/workflows/deploy.yml/badge.svg)](https://github.com/cj0673/twcraft-wiki/actions/workflows/deploy.yml)

這裡是 [寧靜居 Minecraft 伺服器](https://twcraft.net/) Wiki 網站的原始碼，使用 [Docusaurus](https://docusaurus.io/) 框架建置

---

## 如何貢獻

我們非常歡迎任何形式的貢獻，無論是修正錯字、補充內容，或是優化網站功能！

### 在本機執行

1. **Fork & Clone**：將這個專案 Fork 到你自己的 GitHub 帳號，然後 Clone 到你的電腦
2. **安裝依賴**：在專案根目錄執行 `npm install`
3. **啟動網站**：執行 `npm start`，接著在瀏覽器開啟 `http://localhost:3000` 即可看到網站

Wiki 的所有文件都存放在 `/docs` 資料夾中，你可以直接修改裡面的 `.md` 或 `.mdx` 檔案。

### 提交 Pull Request

當你完成修改後，請提交一個 Pull Request。為了讓我能更快了解你的貢獻：

* 請使用**繁體中文**撰寫標題和 Commit 訊息。
* 請清楚說明你「做了什麼」以及「為什麼要這樣做」。
