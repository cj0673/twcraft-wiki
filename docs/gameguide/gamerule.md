### 🌍 世界 / 生物 / 運算

- 蝙蝠不會生成
- 玩家周圍同時最多生成 **42 隻怪物**
- 伺服器渲染距離為 **10 區塊**（view-distance）
- 伺服器模擬距離為 **8 區塊**（simulation-distance）
- 敵對或中立生物會在距離玩家 **24～96 格** 之間生成
- 生物若距玩家超過 **32 格**（水平或垂直）將有機率被清除
- 生物若距玩家超過 **96 格**（水平或垂直）將 **必定被清除**

### 🌾 農務 / 種植 / 管理

- 耕地不再會因玩家或生物的踩踏而變回泥土
- 骨粉可以加速甘蔗、仙人掌、地獄疙瘩的生長
- 潛行狀態下點擊 `滑鼠右鍵` 可以更快速地填滿堆肥桶

### 🧱 方塊 / 建築 / 互動

- 礦車可以被放置在任何方塊上
- 貓站在儲物箱上時仍可開啟儲物箱
- 潛行狀態下可以精準拆除雙層半磚的上半部或下半部

### 🛡️ 生存 / 戰鬥 / 便利

- 龍蛋不再會因玩家互動而傳送
- 不死圖騰即使放在背包中也能夠觸發
- 虛弱狀態下可以取下帶有綁定詛咒的裝備
- 殭屍與殭屍豬人不再會以海龜蛋為攻擊目標
- 村民在被殭屍殺死時有 **50% 機率** 轉變為殭屍村民

### 🌙 世界 / 睡眠 / 時間

- 床在地獄 / 終界爆炸後不會引燃火焰
- 睡覺時不再因為附近有怪物而無法入睡
- 睡覺不再直接跳過夜晚，而是會依入睡人數加快夜晚時間

### ♻️ 掉落物清除

- 以下物品若掉落在地面上超過 **60 秒**，將會被自動清除：  
  泥土、雞蛋、火藥、腐肉、鵝卵石、終界珍珠、深板岩碎石
  
- 其餘物品若掉落在地面上超過 **300 秒**，將會被自動清除
