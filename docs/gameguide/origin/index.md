## 起源（Origin）

想體驗原版 Minecraft 生存，但又擔心建築被破壞、移動不方便？  
起源分流保留了原版的核心玩法，加上領地保護、傳送系統等實用功能，讓你安心建造、輕鬆探險

### 🎮 伺服器資訊

- **版本**：Minecraft Java 1.21.11
- **遊戲模式**：生存模式（保留原版玩法 + 便利功能）

### ✨ 分流特色

- **領地保護**：圈地保護你的建築與財產，不怕被破壞或偷竊
- **傳送功能**：Home 點設置、隨機傳送、玩家互傳，移動更便利
- **靜音模式**：想一個人靜靜玩遊戲？開啟靜音模式，沒人能吵你
- **私人聊天室**：想跟朋友一起玩又怕影響別人？建立私人聊天室，只有你的朋友！
- **稱號系統**：豐富的成就與稱號收集，展現你的遊戲歷程
- **便利功能**：盔甲架編輯器、連鎖砍樹、自動整理、容器鎖定
- **機制優化**：調整原版機制，提升多人遊戲體驗
