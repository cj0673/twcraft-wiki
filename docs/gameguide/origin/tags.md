## 稱號系統

展現你的成就與獨特個性，稱號會顯示在 TabList 和聊天室

### 如何獲得稱號？
>
> - 完成特定遊戲進度
> - 參與活動並完成任務

### 如何查看我擁有的稱號？
>
> - 在遊戲面板點擊「稱號倉庫」
> - 輸入指令 `/tags`

### 不同的稱號顏色分別代表什麼？
>
> - <span style={{ color: '#dea821' }}>服主頒發</span> - 因玩家對伺服器的卓越貢獻或特殊因緣頒發
> - <span style={{ color: '#20dfa0' }}>活動限定</span> - 於活動期間完成指定任務後獲得
> - <span style={{ color: '#26d9d0' }}>完成進度</span> - 在達成特定遊戲進度後獲得
<!--- - <span style={{ color: '#afde21' }}>贊助稱號</span> - 因玩家贊助伺服器的運作而獲得 --->

### 稱號會讓我在遊戲裡擁有其他能力嗎？
>
> 稱號僅供觀賞，不會獲得特殊能力、權限或加成
> <Comment>注意：非指與稱號一同頒發的獎勵</Comment>
> <Comment>例：獲得稱號及免費領地格，該情況為獲得稱號 X 以及獲得領地格 Y，不符本條所述情況</Comment>
